Photo Gallery API Guidelines
========================

This document explains how to extract photos and folder information from the gallery using the API.

1. Basic Usage
-------------
The gallery provides a JSON API that can be accessed by adding URL parameters to the gallery URL.

Base URL: https://photos.budabestapartments.com


2. Getting All Photos and Folders
--------------------------------
To get a complete list of all photos and folders:

URL: https://photos.budabestapartments.com?format=json

Example Response:
{
  "currentPath": ".",
  "folders": [
    {
      "name": "vacation",
      "path": "./vacation",
      "images": [
        "./vacation/beach.jpg",
        "./vacation/sunset.jpg"
      ]
    }
  ],
  "images": [
    "./photo1.jpg",
    "./photo2.jpg"
  ]
}


3. Getting Photos from a Specific Subfolder
-----------------------------------------
To get photos from a specific subfolder:

URL: https://photos.budabestapartments.com?format=json&path=subfolder-name

Example:
https://photos.budabestapartments.com?format=json&path=vacation

Response will include:
- All images in that specific folder
- List of subfolders (if any)
- Current path information


4. JavaScript Example: How to Extract Photos
------------------------------------------
Here's how to fetch photos programmatically from another website:

// Get all photos and folders
async function getAllPhotos() {
    const response = await fetch('https://photos.budabestapartments.com?format=json');
    const data = await response.json();
    return data;
}

// Get photos from a specific subfolder
async function getSubfolderPhotos(folderPath) {
    const url = `https://photos.budabestapartments.com?format=json&path=${encodeURIComponent(folderPath)}`;
    const response = await fetch(url);
    const data = await response.json();
    return data;
}

Example Usage:
const allPhotos = await getAllPhotos();
const vacationPhotos = await getSubfolderPhotos('vacation');


5. Response Format
----------------
The API always returns JSON with this structure:

{
  "currentPath": "path/you/requested",
  "folders": [
    {
      "name": "folder-name",
      "path": "path/to/folder",
      "images": ["array/of/images"] // Only included for root level
    }
  ],
  "images": [
    "array/of/images/in/current/folder"
  ]
}


6. Important Notes
----------------
- All paths are relative to the gallery root
- Image URLs are complete paths relative to the gallery root
- Supported image formats: .jpg, .jpeg, .png, .gif, .webp
- For deep subfolders, use forward slashes: vacation/2023/summer
- URL encode folder paths that contain special characters
- The API is read-only and doesn't support modifying the gallery content
